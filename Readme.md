
# Personal Portfolio Website  
### Author: **Mohd Anas Alam**

This is a fully responsive, modern portfolio website built using **HTML, CSS, and JavaScript**.  
It showcases my profile, skills, education, projects, certifications, and contact details in a clean and professional layout.

---

## 🚀 Features

### ✔ Fully Responsive  
Designed to work smoothly on desktops, tablets, and mobile devices.

### ✔ Light & Dark Mode  
Includes a theme toggle switch to switch between light and dark themes.

### ✔ Smooth Animations  
Sections animate into view using Intersection Observer.

### ✔ Modern UI  
Clean typography, gradient hero section, and animated profile image.

### ✔ Sections Included
- Home / Hero  
- About Me  
- Skills  
- Experience  
- Projects  
- Education  
- Certifications  
- Contact  
- Footer with social links
